# FE Context

The frontend web application rendering interactive decision timelines, Review Queue boards, and feedback exploration interfaces for team members.

## Language

**Review Queue View**:
The interactive UI triage board allowing team leads to confirm, edit, or reject pending Decision Candidates.
_Avoid_: Approvals Page, Pending List, Inbox

**Decision Timeline**:
A chronologically ordered visual stream of confirmed Decision Records grouped by Topic, Channel, and Category.
_Avoid_: Feed, History Stream, Log View

**Decision Card**:
A UI component displaying a single Decision Record or Candidate, its Rationale, Action Items, Governance Score, and Discord source link.
_Avoid_: Post, Item, Box, Widget

**Feedback Board**:
The UI interface displaying External Feedback items linked to affected Decision Records and strategic pivots.
_Avoid_: Review Board, Comments Panel, Notes Tab
