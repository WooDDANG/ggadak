# FE Context

The frontend web application rendering interactive decision timelines, kanban views, and search interfaces for team members.

## Language

**Decision Timeline**:
A chronologically ordered visual stream of Decisions grouped by Topic and Channel.
_Avoid_: Feed, History Stream, Log View

**Decision Card**:
A UI component displaying a single Decision, its Rationale, Action Items, and Discord source link.
_Avoid_: Post, Item, Box, Widget
