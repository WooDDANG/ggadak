## 변경 내용

Discord 로그인 응답의 검증된 서버 목록을 사용하고, 가입 서버 중 GGADDAK 봇이 설치된 서버만 선택합니다. 새로고침 시 HttpOnly 쿠키로 세션을 복원하며, 서버 목록 확인 실패는 정상 빈 목록과 구분합니다.

```text
로그인·세션 복원
  → BE가 반환한 설치 확인된 가입 서버 목록 사용
  → 확인 불가: 로그인 유지·데이터 숨김·재확인
  → 정상 빈 목록: 설치된 가입 서버 없음 안내
  → 정상 목록: 유효한 선택 유지·제거된 선택 교체
```

포커스 복귀·온라인 복귀·수동 요청으로 목록을 재확인합니다. JWT 갱신은 서버 목록 조회와 분리해 주기적인 전체 서버 조회를 제거했습니다. 서버·계정 변경 시 이전 요청 결과와 화면 캐시가 섞이지 않게 합니다. FE 작업은 작업 브랜치와 PR로만 진행하도록 지침도 추가했습니다.

## 검증

- 변경 전: 실제 BE에서 로그인 요청은 200으로 성공했지만 후속 서버 목록 조회가 502로 실패해 FE에 로그인 실패 화면이 표시됐습니다.
- 변경 후: 로그인 응답을 재사용해 즉시 같은 목록을 다시 조회하지 않습니다. 설치 목록 확인 불가도 로그인을 유지한 채 재확인합니다.
- Chrome 브라우저 회귀: 쿠키 복원, 정상 빈 목록과 장애 구분, 재설치 후 목록 갱신, 선택 유지, 서버·계정 전환 후 늦은 응답 차단을 검증합니다.
- 검증 명령: `node --test tests/installed-guild-selection.browser.test.mjs`, `npm run build`.
- 부모 BE의 전체 회귀 183개, 설치 목록 최종 회귀 8개, Bot 53개와 E2E 9개가 통과했습니다.
- Discord의 실제 봇 제거·재설치 조작은 자동화하지 않았으며, 외부 응답과 이벤트는 테스트 fixture로 제어했습니다.
