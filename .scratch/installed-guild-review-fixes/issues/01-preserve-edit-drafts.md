# 01: 포커스 복귀와 서버 재확인 시 편집 초안 보존

**What to build:** 사용자가 카드나 동기화 채널을 편집하다 다른 창에서 돌아와도, 계정과 적격 서버가 같으면 저장 전 작업을 유지한다. 서버 확인 중이거나 접근할 수 없을 때는 해당 서버 데이터를 안전하게 차단한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 카드 편집 중 포커스 복귀·온라인 복귀·수동 서버 재확인이 성공하고 선택 서버가 계속 적격이면 입력한 Decision Record 초안과 편집 상태를 유지한다.
- [x] 저장 전 동기화 채널 선택도 동일한 재확인 후 유지하며, 자동 저장이나 변경 요청 재전송으로 보존을 대신하지 않는다.
- [x] 재확인 중과 설치 정보 확인 불가 상태에서는 기존 서버 데이터 표시 및 편집 제출을 차단한다. 동일 계정·적격 서버로 복구하면 초안을 다시 사용할 수 있다.
- [x] 봇 제거·사용자 탈퇴로 선택 서버가 부적격이면 적격 서버 또는 서버 없음 화면으로 전환하며, 이전 서버 초안과 응답을 새 서버에 표시하지 않는다.
- [x] 로그아웃·계정 전환 시 이전 계정의 초안과 서버 데이터를 정리한다.
- [x] 실제 화면의 카드 입력과 채널 체크를 조작하는 브라우저 회귀로 변경 전 손실을 재현하고, 동일 서버 유지·확인 불가 후 복구·서버 및 계정 변경을 검증한다. 인증 상태만 보여주는 Probe로 검증을 대체하지 않는다.
- [x] FE 작업은 작업 브랜치와 PR로 제출하며 PR 제목·본문은 한글로 작성한다. 빌드와 테스트는 Herdr 검증 pane에서 실행한다.
