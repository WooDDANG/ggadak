# 02: Discord 인증 취소 후 정상 화면 복귀

**What to build:** Discord 로그인을 취소하거나 콜백 정보가 유효하지 않아도 오류 안내에서 처음 화면으로 돌아가거나 새 인증을 시작할 수 있게 한다. 유효한 기존 브라우저 세션은 정상적으로 복원한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] Discord 인증 취소 콜백에서 오류 안내가 표시되고, ‘처음 화면으로’를 누르면 로그인 확인 상태에 멈추지 않는다.
- [x] 기존 유효한 브라우저 세션이 없으면 로그인 시작 화면으로, 유효한 세션이 있으면 해당 계정의 세션·설치된 가입 서버 선택 상태로 복귀한다.
- [x] 불완전한 콜백이나 인증 실패도 종료 가능한 상태가 되며, URL 정리 후 새로고침해도 무한 로딩하지 않는다.
- [x] ‘다시 로그인’은 새 인증 절차를 시작하고 일회용 OAuth state나 code를 재사용하지 않는다. 정상 콜백의 로그인 요청은 중복 전송하지 않는다.
- [x] 실제 콜백 화면에서 인증 취소→처음 화면→재로그인 흐름을 조작하는 브라우저 회귀를 추가한다. 기존 세션 유무와 정상 로그인 성공도 함께 검증한다.
- [x] FE 작업은 작업 브랜치와 PR로 제출하며 PR 제목·본문은 한글로 작성한다. 빌드와 테스트는 Herdr 검증 pane에서 실행한다.
