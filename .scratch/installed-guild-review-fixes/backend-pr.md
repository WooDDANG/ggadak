## 변경 내용

`feat/installed-guild-selection`을 기준으로 리뷰 보완을 새 브랜치에 분리했습니다. 서버 재확인 시 저장 전 편집이 사라지고 인증 취소 후 무한 로딩하던 문제를 수정한 FE 커밋 `18e5b43`을 연결합니다. FE는 별도 [PR #4](https://github.com/likelion-kkadak/frontend/pull/4)로 검토합니다.

```text
서버 재확인 → 화면 숨김·조작 차단
  → 같은 계정·적격 서버: 편집 초안 유지
  → 계정·선택 서버 변경: 이전 화면 정리
인증 취소 → 기존 쿠키 복원 또는 로그인 화면
예약 갱신 + 401 복구 → JWT 요청 1회 공유
```

실제 FE와 실제 BE·격리된 DB를 연결하는 Chrome 회귀 4개를 추가하고, 티켓 완료 기록과 재현 가능한 검증 명령을 문서화했습니다.

## 검증

- 변경 전: 실제 화면에서 포커스 복귀 후 채널 선택 손실, 인증 취소 후 무한 로딩을 재현했습니다. 예약 갱신과 401 경합에서는 토큰 요청이 2회였습니다.
- 변경 후: 카드·채널 초안 유지, 확인 불가 상태 차단·복구, 계정 전환 후 이전 데이터 접근 거부, 인증 취소 후 정상 복귀를 확인했습니다.
- 실제 BE 토큰 요청에 만료 조회 3개를 겹쳐 토큰 요청 1회·각 조회 재시도 1회를 확인했습니다. 변경 요청은 재전송하지 않습니다.
- `npm run typecheck` 및 최종 `npm test` 통과: BE 184개, Bot 53개, FE 12개, E2E 13개. 실제 FE→BE Chrome 4개 모두 실행·통과했습니다.
- 최초 전체 실행에서 브라우저 테스트 파일의 공유 Vite 캐시 충돌을 발견해 직렬 실행으로 보완했고, 이후 전체 검증이 통과했습니다.
- 최종 리뷰 Standards·Spec 미해결 지적 0개. Discord 외부 관측만 제어하며 BE 응답은 대체하지 않습니다. 실제 Discord 서버의 설치·탈퇴는 수행하지 않았습니다.

## 병합 영향

- 되돌리기: 커밋과 submodule 포인터를 되돌릴 수 있습니다.
- 영향 범위: FE 브라우저 인증·JWT 갱신·서버 선택·편집 상태와 연동 회귀.

- FE 포인터는 PR #4의 검토·병합 대기 커밋입니다. 기본 브랜치 직접 push나 자동 merge는 하지 않습니다.
