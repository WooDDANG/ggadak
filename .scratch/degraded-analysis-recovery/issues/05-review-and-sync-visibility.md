# 05: 손상 후보와 건너뛴 세션 표시

**What to build:** 검수자는 후보의 관계 손상을 확인하고, 사용자는 동기화 상세에서 건너뛴 세션의 복구 상태와 재분석을 관리한다.

**Blocked by:** 01: 손상된 분석 세션의 검증과 후보 발행, 02: 실패 세션 기록과 동기화 진행, 03: 건너뛴 세션의 자동·수동 복구, 04: 실패 입력 보관 만료와 새 분석

**Status:** ready-for-agent

- [ ] Review Queue의 손상 세션 후보에 관계 일부가 제거됐다는 경고를 표시한다.
- [ ] 동기화 상세는 완료 상태와 손상·건너뜀 건수, 세션별 사유·자동 재시도 상태 및 복구됨을 함께 표시한다.
- [ ] 재시도 중 중복 요청을 막고, 재시도 소진·입력 만료 시 가능한 다음 동작을 표시한다.
- [ ] 입력 만료 후 현재 Discord 대화로 새 분석하는 동작은 원래 입력 재분석과 구분한다.
