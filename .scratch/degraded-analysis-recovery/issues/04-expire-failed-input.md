# 04: 실패 입력 보관 만료와 새 분석

**What to build:** 실패 세션을 최초 입력으로 제한 기간 재분석하고, 입력이 만료되면 현재 Discord 메시지를 별도 요청으로 분석할 수 있게 한다.

**Blocked by:** 03: 건너뛴 세션의 자동·수동 복구

**Status:** ready-for-agent

- [ ] 최초 Analysis Request 생성 시점부터 30일간 실패 입력을 보관하며 재시도해도 기한을 연장하지 않는다.
- [ ] 만료 시 원래 입력을 사용하는 재시도를 중단하고 실패 상태와 원인·메시지 ID는 보존한다.
- [ ] 다른 Decision Record, 증거 또는 진행 중 분석이 참조하는 데이터를 손상시키지 않는다.
- [ ] 만료 후 사용자가 요청하면 현재 Discord 메시지로 새로운 Analysis Request를 만들고 원래 입력 재현과 구분한다.
- [ ] 만료 경계, 재시도 중 만료, 삭제·수정된 Discord 메시지와 참조 공유를 테스트한다.
