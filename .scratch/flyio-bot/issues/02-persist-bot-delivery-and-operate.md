# 02: Bot 전달 기록 보존과 Fly.io 운영 검증

**What to build:** Machine이 재시작하거나 재배포돼도 Bot의 미전달 데이터가 보존되고, 운영자가 Fly.io 웹 화면에서 설정과 상태를 확인할 수 있다.

**Blocked by:** 01: Fly.io에서 BE와 Bot 함께 실행

**Status:** ready-for-agent

- [x] 분석 전달 및 길드 접근 이벤트의 내구성 기록이 영구 볼륨에 저장되고 재시작 후 복구된다.
- [x] SQLite와 Bot 기록이 같은 단일 Machine 볼륨에서 권한 문제 없이 읽고 쓰며, 기존 데이터 이전 시 덮어쓰지 않는다.
- [x] 필요한 Discord·BE 인증 환경변수, 볼륨, 단일 Machine 제약, 백업·복구 및 로그 확인 절차를 웹 운영 문서에 명시한다.
- [x] 상시 실행의 요금과 무료 체험 한도 확인 위치를 명시한다.
- [ ] 임시 저장소와 가짜 자격 증명을 이용해 재시작 복구와 장애 시 전달 보존을 검증한다. FE 테스트는 실행하지 않는다.

## 검증 메모

Bot의 기존 재시작·재전송 테스트가 통과했다. Fly 볼륨에서 실제 Discord 연결과 재배포 복구는 아직 확인하지 못했다.
