# 06: 동기화 시작 위치와 범위를 터미널 로그에 기록

**What to build:** FE에서 요청한 Sync Job을 운영자가 추적할 수 있도록 Bot이 채널별 동기화 시작 시 적용한 스캔 경계와 모드를 터미널 로그에 기록한다. checkpoint와 실제로 가져온 메시지 범위를 구분해 증분 스캔인지 전체 스캔인지 확인할 수 있어야 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 채널별 스캔을 시작할 때 Sync Job ID, guild ID, channel ID, 전체·증분 스캔 모드와 적용된 시작 경계 메시지 ID를 기록한다. checkpoint가 없으면 경계가 없음을 명시한다.
- [ ] 스캔 결과가 있으면 실제 수집한 첫 메시지와 마지막 메시지의 ID 및 수집 건수를 기록하고, 수집 결과가 없으면 별도로 구분한다.
- [ ] 저장된 스캔 또는 전송 상태에서 재개하는 경우 새 스캔과 구분하고, 실제로 적용된 경계를 기록한다. 사용 가능한 정보가 없으면 추정하지 않는다.
- [ ] 동기·비동기 전달 경로 모두에서 로그가 Render 터미널에 출력되며, 메시지 본문과 자격증명은 포함하지 않는다.
- [ ] checkpoint가 있는 증분 스캔, checkpoint가 없는 스캔, 전체 스캔, 빈 결과와 재개 경로에서 로그의 경계와 모드가 실제 동작과 일치함을 테스트한다.
