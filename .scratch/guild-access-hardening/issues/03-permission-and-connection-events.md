# 03: 권한 변경·Bot 탈퇴·연결 복구를 서버별 상태에 반영

**What to build:** 멤버 역할이나 서버 권한이 바뀌면 오래된 권한을 무효화한다. Bot 탈퇴는 설치 상태에 반영하고, 이벤트를 놓쳤을 가능성이 있는 서버는 필요한 재검증을 거쳐 이용하도록 한다. Bot 설치와 사용자 가입 권한을 서로 혼동하지 않는다.

**Blocked by:** 02: 사용자 탈퇴 이벤트로 서버 접근 즉시 차단 — 인증된 이벤트 전달과 무효화 기반을 사용한다.

**Status:** ready-for-agent

- [ ] 멤버 역할 변경, 역할 권한 변경·삭제, 서버 소유권 변경으로 영향을 받는 관리 권한을 무효화하고 재검증 전에는 관리 작업을 허용하지 않는다.
- [ ] Bot이 실제로 제거된 서버의 Bot Installation Status를 갱신한다. 사용자 가입 정보와 기존 Decision Record는 보존한다.
- [ ] 서버의 일시적 unavailable 상태는 Bot 제거로 확정하지 않는다. 이때 불확실한 상태를 성공한 관측처럼 캐시하지 않는다.
- [ ] Gateway Resume의 이벤트 재생 완료, 재연결 실패, Bot/BE 재시작, 이벤트 전달 공백을 구분하고 서버별 이벤트 신뢰 상태를 복구한다.
- [ ] 이벤트 연속성을 확인할 수 없는 동안에는 관련 서버의 캐시된 권한만으로 데이터를 반환하지 않는다. 실제 접근 시 필요한 재검증으로 복구할 수 있다.
- [ ] 변경 이벤트가 연속되거나 재시도 순서가 뒤집혀도 예전 관리 권한·설치 상태가 최신 상태를 덮어쓰지 않는다.
- [ ] 권한 상실 후 관리 작업 거절, Bot 미설치 서버의 가입 사용자 결정 조회, 일시 장애와 재접속 복구를 Bot→HTTP 경계에서 검증한다.
- [ ] 추가 Portal 설정과 이벤트 관측·복구 절차를 운영 문서에 기록한다.
