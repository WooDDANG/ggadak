# 02: 사용자 탈퇴 이벤트로 서버 접근 즉시 차단

**What to build:** Discord에서 사용자가 탈퇴·추방·차단되면 Bot이 변경을 전달하고 BE가 해당 사용자와 서버의 접근을 즉시 무효화한다. 유효한 기존 JWT와 다른 브라우저 세션으로도 탈퇴한 서버 데이터를 다시 읽을 수 없어야 한다. 기존 서버 격리 회귀 검증을 이 동작과 함께 수행한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 멤버십 이벤트 수신을 위한 intent 설정과 Portal 전제조건을 명시한다. 수신할 수 없는 상태를 정상 수신 중으로 표시하지 않는다.
- [ ] Bot→BE 무효화 요청은 서비스 인증으로 보호하며 미인증·잘못된 토큰·사용자 JWT 요청을 거절한다.
- [ ] 실제 탈퇴 이벤트가 반영되면 서버 목록에서 제거되고 모든 기존 사용자 세션의 결정·검색·채널·Bot Installation Status 요청이 403을 반환한다.
- [ ] 다른 사용자와 해당 사용자의 다른 가입 서버는 계속 접근할 수 있다. 서버 ID·결정 ID 변조도 차단한다.
- [ ] 이벤트 전달 실패 후 재시도와 프로세스 재시작으로 변경을 잃지 않으며 중복 처리는 무해하다. 전달 연속성을 잃으면 관련 권한을 신뢰하지 않는다.
- [ ] 이벤트보다 늦게 도착한 과거 상태나 진행 중이던 OAuth 조회 결과가 탈퇴한 사용자의 권한을 되살리지 않는다. 재가입은 새로 확인한 가입 정보로만 허용한다.
- [ ] Bot 이벤트→BE 실제 HTTP 접근까지 회귀 검증하고 생성 API 계약과 운영 안내를 갱신한다.
