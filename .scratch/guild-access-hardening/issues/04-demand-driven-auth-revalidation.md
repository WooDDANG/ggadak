# 04: 고정 주기 권한 재조회를 제거하고 JWT 갱신과 분리

**What to build:** 웹을 열어두기만 하면 발생하는 주기적 Discord 권한 재조회를 없앤다. 로그인은 유지하면서 이벤트가 유효한 권한 캐시를 무효화하도록 하고, 로그인·복구·권한 확인이 필요한 실제 요청에서만 Discord에 재검증한다.

**Blocked by:** 03: 권한 변경·Bot 탈퇴·연결 복구를 서버별 상태에 반영 — 02의 탈퇴 무효화와 함께 이벤트 수신 범위·연속성을 판정할 수 있어야 주기 조회를 안전하게 제거할 수 있다.

**Status:** resolved

- [x] FE의 고정 주기 세션 복원/권한 조회 타이머를 제거한다. 시간이 10분·15분 지났다는 이유만으로 Discord 서버 목록·권한을 조회하지 않는다.
- [x] 만료된 JWT는 실제 API 요청에서 서버 세션으로 복구한다. 이 JWT 재발급 자체는 Discord 권한 재조회를 유발하지 않는다.
- [x] 최초 로그인과 필요한 복구 시점에 가입 정보를 확인한다. 정상적으로 이벤트를 수신하는 서버의 유효한 권한은 반복 조회하지 않는다.
- [x] Bot 미설치·멤버 intent 미설정·연결/전달 공백 등으로 이벤트를 신뢰할 수 없는 서버는 실제 데이터 접근 전에 재검증한다. 무조건 영구 허용하거나 일정 간격의 전체 조회로 되돌아가지 않는다.
- [x] 동시에 필요한 재검증 요청은 공유하고, 이벤트와 조회가 경합해도 무효화된 권한을 되살리지 않는다. Discord 장애 시 접근은 보류하되 유효한 로그인 세션은 유지한다.
- [x] 권한 재검증 결과에 따라 FE의 서버 목록·선택 서버·관련 캐시를 갱신한다. 사용자 전환·로그아웃·재시도·늦은 응답으로 이전 사용자/서버 데이터를 표시하지 않는다.
- [x] 고정 7일 세션 만료와 JWT 만료 검증을 유지한다. 두 사용자 서버 격리, 이벤트 후 접근 거절, JWT 만료 복구, 재가입과 Bot 없는 서버 접근을 HTTP·FE 사용자 흐름에서 검증한다.
- [x] 가짜 시간으로 앱을 오래 열어둬도 주기적 권한 조회가 발생하지 않음을 검증하고, 실제 접근이 필요한 때 재검증함을 별도로 확인한다.
- [x] 기존 15분 캐시/10분 주기 복원 설명과 생성 API 계약을 새 동작에 맞게 갱신한다.
