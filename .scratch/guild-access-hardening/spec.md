# 이벤트 기반 서버 접근 권한 보완

## 승인한 방향

2026-11-03: 사용자가 고정 주기 권한 재조회 대신 Bot 이벤트로 변경을 반영하고, 필요한 시점에만 재검증하는 방향으로 티켓 재작성을 요청했다. 이전의 15분 캐시 수명 고정 요구사항은 이 명세로 대체한다. 이후 사용자의 implement 호출로 네 티켓 구현이 승인됐다.

## 사용자 동작

- 로그인한 사용자는 자신이 가입한 Discord 서버의 목록과 데이터만 볼 수 있다. 서버 ID나 결정 ID를 바꿔도 접근 범위를 넘을 수 없다.
- 사용자 탈퇴·추방·차단 이벤트를 BE가 반영한 뒤에는 해당 사용자와 서버의 접근을 즉시 거절한다. 전체 사용자를 로그아웃시키거나 다른 서버 접근까지 제거하지 않는다.
- 역할·관리 권한 변경도 이벤트로 무효화한다. 재검증 전에는 이전 관리 권한을 재사용할 수 없다.
- Bot 탈퇴는 Bot Installation Status를 바꾸는 사건이다. 해당 서버의 모든 사용자 가입 정보를 삭제하거나 기존 결정 기록을 숨기는 근거로 사용하지 않는다.
- Discord 일시 장애로 서버가 unavailable인 경우와 Bot이 실제로 제거된 경우를 구분한다.
- 웹이 열려 있다는 이유만으로 10분·15분마다 Discord 서버 목록과 권한을 다시 조회하지 않는다. JWT의 만료와 갱신은 Discord 권한 재조회와 분리한다.
- 로그인·필요한 재접속 복구·이벤트 수신 상태를 신뢰할 수 없는 서버의 데이터 요청에서 필요한 범위만 재검증한다. Bot이 없거나 멤버 이벤트 수신 권한이 없는 서버도 기존 가입 사용자 접근 정책을 유지한다.

## 이벤트 신뢰성과 복구

- 사용자 멤버십 이벤트에는 GUILD_MEMBERS intent와 Discord Developer Portal 설정이 필요하다. 설정이 없다고 이벤트가 수신되는 것으로 간주하지 않는다. 실제 Portal 변경은 구현 완료와 구분해 기록한다.
- Bot→BE 변경 전달은 서비스 인증으로 보호한다. 사용자 JWT나 미인증 요청으로 다른 사용자의 권한을 무효화할 수 없어야 한다.
- 중복·전달 실패·재시도·순서 역전·재시작을 다룬다. 중복 이벤트는 무해하고, 새 탈퇴/권한 변경 이후 늦게 완료된 OAuth 재조회가 과거 권한을 되살릴 수 없어야 한다.
- Gateway Resume 성공 시 재생한 이벤트 반영 완료를 확인하고, 복구 불가·Bot/BE 재시작·전달 장애 등으로 연속성이 불명확하면 관련 권한을 재검증 대상으로 전환한다.
- Bot의 연결/전달 상태와 이벤트 수신 가능 범위를 근거로 캐시 신뢰 여부를 판정한다. 캐시가 15분을 지났다는 이유만으로 조회하지 않으며, 이벤트 누락 가능성을 무시한 영구 허용으로 바꾸지도 않는다.
- 신뢰할 수 없는 권한은 실제 데이터 접근 전에 재검증한다. 동시 요청은 가능한 범위에서 조회를 공유하고, Discord 장애 시 데이터 접근은 보류하되 유효한 로그인 세션 자체는 유지한다.
- 새 권한 판정 전에 FE가 캐시를 표시하거나 요청을 재시도하여 서버 경계를 넘지 않도록 한다. 즉시 무효화의 기준은 BE의 이벤트 반영 시점이며, 별도 웹 실시간 푸시 기능은 범위에 포함하지 않는다.

## 기존 보안 보완 유지

- 기존 External Feedback 조회·등록 API는 Bot 서비스 인증만 허용한다. 미인증 요청과 사용자 JWT로 전역 피드백에 접근할 수 없어야 한다.
- Bot의 `/피드백입력`은 서비스 자격증명으로 계속 동작한다. 웹의 서버별 External Feedback 기능은 기존 보류 상태를 유지한다.

## 검증과 계약

- 각 티켓은 Bot 이벤트/BE 호출 경계, 실제 HTTP API, 필요한 FE 사용자 흐름에서 자체 회귀 테스트를 포함한다. 검증만 별도 마지막 티켓으로 미루지 않는다.
- 서로 다른 서버에 속한 두 사용자와 여러 세션을 사용해 목록·결정·검색·채널·Bot Installation Status의 격리를 검증한다.
- 고정 7일 세션 만료, 짧은 JWT 만료, 로그아웃과 사용자 전환 격리는 유지한다. 주기 타이머 없이 실제 요청에서 JWT 만료를 복구한다.
- 생성 API 계약, 인증 운영 문서와 기존 세션 정책 설명을 구현 동작에 맞게 갱신한다.

## 공식 근거

- [Discord Gateway Events](https://docs.discord.com/developers/events/gateway-events): Guild Member Remove/Update, Guild Delete와 unavailable 구분.
- [Discord Gateway](https://docs.discord.com/developers/events/gateway): GUILD_MEMBERS intent, Resume 이벤트 재생과 복구 불가 시 재연결.
