# 03: 실제 AGY 병렬 처리량 측정

**What to build:** 같은 대표 입력·계정·모델에서 병렬 수 1·2·4의 처리량과 지연·오류·자원 사용량을 비교해 운영값 판단 근거를 남긴다.

**Blocked by:** None (can start immediately). 직접 분석 경로를 사용하므로 Sync Job 복구와 독립적이다.

**Status:** needs-info

- [x] 호출·토큰·출력·시간 예산을 명시한 기존 벤치마크를 사용한다.
- [x] fixture와 실제 AGY 측정 결과를 구분하고 실행 조건·완료 지연·대기·오류·자원 사용을 기록한다.
- [ ] 비교 가능한 성공 표본과 서비스 지연 조건을 만족할 때만 측정 범위의 권장 N을 제시한다.
- [x] 실제 할당량·로그인·모델 연결 실패도 근거로 남기며 환경설정을 자동 변경하지 않는다.

## 측정 결과와 남은 작업

초기 예산 내 공급자 호출 14회, 보고된 사용 토큰 197375로 종료했다. N=1은 4개 세션을 완료했으나 N=2 중 예산 예약 한도에 도달했고 N=4는 실제 공급자 호출을 하지 못했다. 서비스 probe도 응답하지 않아 유효한 운영 추천은 없다. provider의 병렬 제한이나 quota 오류로 단정하지 않는다.

비교 완료를 위해 실행 중인 BE와 추가 토큰 예산이 필요하다. 사용자에게 추가 호출 없이 결과 기록 또는 BE 연결 후 추가 40만 토큰 재측정을 선택하도록 질문했다. 승인 없이 예산을 늘리지 않는다. 운영 동시성은 기본값 1을 유지한다.
