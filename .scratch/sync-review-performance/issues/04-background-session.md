# 04: 백그라운드 세션 확인 중 화면 깜빡임 제거

**What to build:** 로그인한 사용자가 창으로 돌아오거나 토큰을 갱신할 때 기존 화면과 작업 중인 입력이 사라지지 않게 한다.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 이미 로그인된 상태의 세션 확인은 화면을 loading으로 바꾸거나 유효한 토큰을 먼저 지우지 않는다.
- [x] 동일 사용자·서버의 복원 성공 시 데이터 캐시와 화면·입력 상태를 보존한다.
- [x] 최초 로그인, 실제 만료, 로그아웃, 다른 사용자 전환, 권한 미확인 장애의 보호 동작을 유지한다.
- [x] 브라우저에서 지연된 세션 확인 중 DOM이 유지되고 이후 입력·서버 선택이 보존됨을 검증한다.
- [x] 로그인 유지 기간은 고정 7일로 유지한다.

## Answer

공개 HTTP·브라우저 회귀 검증과 전체 218개 테스트가 통과했다. Standards/Spec 별도 리뷰의 수정 필요 항목은 각각 0건이다. 상세 결과는 상위 구현 검증 기록을 따른다.
