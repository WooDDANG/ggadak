# 02: Review Queue 전체 목록 반복 조회 제거

**What to build:** 검수 화면에서 현재 상태와 페이지의 후보만 읽고, 교체할 확정 결정과 과거 이력은 필요할 때 페이지별로 불러온다.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 비활성 화면에서 전체 결정·전체 검수 큐 폴링을 하지 않는다.
- [x] 대기·보류 상태 전환과 페이지 이동을 지원하고 현재 페이지의 갱신만 수행한다.
- [x] 교체 대상은 선택기를 열 때 확정 기록을 페이지별로 조회하며 선택한 버전 snapshot을 보존한다.
- [x] 확정·반려 이력은 빈 검수 큐에서도 지연 조회할 수 있고 서버별 캐시를 격리한다.
- [x] 검수 후 목록·집계를 갱신하며 version 충돌 시 최신 후보를 확인한 뒤 재선택하도록 한다.
- [x] 요청 수·반환 건수 개선을 재현 가능한 브라우저 테스트로 확인한다.

## Answer

공개 HTTP·브라우저 회귀 검증과 전체 218개 테스트가 통과했다. Standards/Spec 별도 리뷰의 수정 필요 항목은 각각 0건이다. 상세 결과는 상위 구현 검증 기록을 따른다.
