# 06: 사람이 검수하는 서비스 평가 정답 준비 도구

**What to build:** 공개 AMI 원문/기존 정답과 우리 추가 후보·관계 정답을 구별해 준비하고, 사람이 검수한 정답·의미 대응을 고정해 평가에 사용할 수 있다. 모델 연결 없이 오프라인으로 검증 가능하다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 기존 AMI 변환 결과의 input/originalGold/coverage를 유지하고 우리 후보·관계·관측·누락 값의 추가 gold를 별도 버전으로 기록한다.
- [ ] 입력 자료 선택·주석 초안 import/export·인간 검수 표시를 제공한다. 고정 응답/사람 작성 초안으로 경로를 검증하며 실제 AI 초안 생성·유료 실행은 필수가 아니다.
- [ ] 검수되지 않은 gold를 최종 정답으로 쓰지 않고 test gold 고정·수정 이력·입력 출처/checksum·독립 회의 분할을 기록한다.
- [ ] 후보 의미 일대일 대응과 관계 끝점/종류/방향 대응을 입력할 수 있어 중복 TP와 문자열/생성 ID 일치 기반 평가를 피한다. 미완전 정답에서는 전체 recall을 N/A로 표시한다.
- [ ] AMI 요약에 없는 제안을 자동 FP로 만들지 않고 624개 연결 있는 결정/70개 연결 없는 결정의 적용 범위를 구별한다. 논증 inventory를 우리 그래프 gold로 임의 치환하지 않는다.
- [ ] 한국어/영어/번역본·원본 자료 권한·주석 coverage를 구별한다. 한국어 gold 50개는 목표이며 도구 완료를 한국어 품질 검증 완료로 표시하지 않는다.
- [ ] 오프라인 fixture로 정답 분리·검수 누락·분할 누출·후보/관계 중복·N/A·schema 검증을 확인하고 도구 사용법을 문서화한다.

## Scope clarification

기존 production 분석 알고리즘과 호출부를 새 workflow로 전환하는 리팩토링이다. 구형 경로·중복 정책은 전환 뒤 제거하고 단일 호출 baseline만 평가 도구에 보존한다. 주 검증 경계는 승인된 실제 HTTP API·임시 SQLite·고정 AI 응답이다.
