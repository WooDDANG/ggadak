# 01 — 봇 비대칭 수집 윈도우 및 하이브리드 디바운스 파이프라인

**What to build:**
디스코드 봇(`apps/bot`)이 채널 유형(스레드 채널 vs 일반 채널)과 트리거 유형(수동 📌 핀 vs 자연어 합의 키워드)에 따라 최적화된 비대칭 윈도우를 수집하고, 버스트 대화를 슬라이딩 디바운스로 안정적으로 묶어 백엔드로 전송하는 동작.

**Blocked by:** None — can start immediately.

**Status:** closed

- [x] 스레드 채널에서 트리거 시 시작 메시지부터 최대 100건까지의 전체 대화 히스토리를 수집한다.
- [x] 일반 텍스트 채널에서 트리거 시 트리거 메시지 기준 이전 15개, 이후 5개의 비대칭 윈도우(연속 트리거 시 최대 40건 병합)를 수집한다.
- [x] 수동 📌 핀 반응은 0초 즉시 수집하고, 자연어 키워드 매칭은 15초 슬라이딩 디바운스(메시지 추가 시 15초 리셋, 최대 60초 상한)를 적용한다.
- [x] 채널별 분석 진행 중 중복 요청을 방지하기 위한 인메모리 락과 60초 만료 세이프티 TTL을 보장한다.
- [x] 수집된 원시 메시지 배열이 백엔드 분석 API(`POST /api/discussions/analyze`)로 정상 전송된다.
