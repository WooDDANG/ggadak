# 05 — 합집합 3중 게이트 및 사후 거버넌스 스코어러 연동

**What to build:**
전처리된 세션 청크 중 수동 핀, 리액션 3개 이상, 합의/결정 어미 매칭의 합집합 조건을 판정하여 신호 부재 시 무비용 조용한 회수(Silent Cleanup)를 수행하고, 신호 존재 시에만 LLM을 호출하여 1인 독백 액션을 포함한 사후 거버넌스 점수(1.0~4.0)를 확정·저장하는 통합 파이프라인.

**Blocked by:** 01 — 봇 비대칭 수집 윈도우 및 하이브리드 디바운스 파이프라인, 04 — 30분 시간 갭 및 형태소·블록 임베딩 TextTiling 토픽 분할기

**Status:** closed

- [x] 세션 내에 수동 📌 핀, 이모지 반응 수 $\ge 3$개, 합의·결정 종결어미(`~합시다`, `~하기로 함`, `~픽스`, `~확정`) 패턴 중 하나라도 있는지 판정하는 합집합 3중 게이트를 구현한다.
- [x] 3개 신호가 모두 없는 잡담 세션은 LLM 호출 및 DB 저장을 생략하고, 봇에게 `{ found: false }`를 응답하여 `👀` 이모지를 조용히 회수한다.
- [x] 3개 신호 중 하나라도 만족하면 Vercel AI SDK(LLM)를 호출하여 의사결정을 추출하고, 1인 독백 발화도 액션 아이템으로 보존한다.
- [x] LLM 추출 성공 시 Rationale 및 ActionItem 존재 여부와 참여자 수를 종합하여 최종 1.0~4.0 거버넌스 점수를 산출하고 DB에 영속화한다.
- [x] 전체 파이프라인(봇 수집 ➔ 백엔드 전처리 ➔ 3중 게이트 ➔ LLM ➔ DB)을 아우르는 E2E 테스트를 작성하고 통과한다.
