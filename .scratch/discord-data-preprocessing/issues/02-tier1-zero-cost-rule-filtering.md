# 02 — Tier 1 비용 제로 노이즈 필터링 및 가상 리액션 변환기

**What to build:**
백엔드(`apps/be`)로 유입된 원시 메시지 스트림에서 봇 메시지, 커맨드 호출, 순수 감탄사 잡담을 0원 비용으로 즉시 걸러내고, 링크/미디어 정규화 및 합의어의 가상 리액션 변환을 수행하는 전처리 엔진.

**Blocked by:** None — can start immediately.

**Status:** closed

- [x] `author.bot === true`인 봇 발화 및 `^[/!?.~-]`로 시작하는 명령어 메시지를 즉시 삭제한다.
- [x] 텍스트 없이 단독으로 첨부된 URL은 `[Link: url]`, 첨부 미디어는 `[Attachment: filename]` 메타 태그로 변환하여 보존한다.
- [x] "ㅇㅋ", "좋습니다", "동의", "굿", "넵", "찬성", "👍" 등 합의성 단문 발화는 직전 발화의 가상 동의 리액션 카운트(+1)로 흡수 변환하고 메시지 목록에서 제거한다.
- [x] "ㅋㅋ", "ㅎㅎ", "ㅠㅠ", "아", "헐" 등 순수 감탄사성 잡담 메시지는 완전 삭제한다.
- [x] 필터링 전후의 단위 테스트를 통해 토큰 절감 및 메시지 정합성을 검증한다.
