# 03 — 답글 및 멘션 기반 대화 얽힘 해소 엔진

**What to build:**
스레드가 없는 공개 채널에서 여러 화자가 교차 발화할 때, 답글 및 멘션 메타데이터와 시간 근접성을 바탕으로 대화 인과 트리를 복원하고 인과순 정렬 평탄화 배열(`DisentangledThread[]`)로 재구성하는 전처리 모듈.

**Blocked by:** 02 — Tier 1 비용 제로 노이즈 필터링 및 가상 리액션 변환기

**Status:** closed

- [x] `referenceMessageId`(답글)가 존재하면 해당 부모 메시지의 직계 자식 노드로 연결하여 1차 방향성 트리(Directed Forest)를 구축한다.
- [x] 특정 유저 `@멘션`이 포함되어 있고 해당 유저가 직전 5분 이내에 발화한 이력이 있으면 가상 인과 링크로 연결한다.
- [x] 동일 화자가 60초 이내에 연달아 보낸 발화(Burst)는 단일 노드로 병합한다.
- [x] 직전 2분 이내에 상호작용이 있었던 활성 스레드가 있으면 해당 스레드로 후속 발화를 편입하고, 2분 이상 침묵 후 발화는 신규 스레드 루트로 분기한다.
- [x] 트리를 순회하여 인과관계 순서로 정렬된 `DisentangledThread` 배열 객체를 생성한다.
