# 04 — 30분 시간 갭 및 형태소·블록 임베딩 TextTiling 토픽 분할기

**What to build:**
30분 무발화 시간 갭 기반의 1차 물리적 분할과, 15개 이상 긴 세션 대상의 형태소 정제 + 슬라이딩 블록 임베딩 코사인 깊이 점수(0.35) 기반 토픽 드리프트 분할을 수행하여 단독 선언(1개)부터 최대 100개까지의 안전 세션을 생성하는 분할기.

**Blocked by:** 02 — Tier 1 비용 제로 노이즈 필터링 및 가상 리액션 변환기, 03 — 답글 및 멘션 기반 대화 얽힘 해소 엔진

**Status:** closed

- [x] 30분 이상 대화 공백이 발생하면 별도의 독립 세션으로 1차 분할한다.
- [x] 세션 내 메시지가 15개 이상인 경우, 한국어 형태소 분석기(`garu-ko`/Kiwi)로 실질 형태소를 추출하고 3~5개 발화 블록 임베딩을 구성한다.
- [x] `@xenova/transformers` ONNX 다국어 경량 모델을 통해 인접 블록 간 코사인 유사도 깊이 점수(Depth Score $\ge 0.35$)를 산출하여 토픽 전환 지점을 분할한다.
- [x] 세션 크기가 최소 1개(단독 선언/공지 보존)에서 최대 100개 메시지를 초과하지 않도록 안전 가드레일을 적용한다.
