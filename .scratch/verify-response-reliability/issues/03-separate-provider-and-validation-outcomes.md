# 03: AI 호출 성공과 검증 성공 지표 구분

**What to build:** 운영자가 NVIDIA 호출의 성공과 그 응답을 사용하는 Analysis Request의 검증 결과를 로그와 지표에서 각각 확인해, API 응답 성공 뒤 발생한 스키마 오류를 파악할 수 있도록 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Provider 응답 성공과 Verify 스키마 검증 성공·실패를 상관관계 ID와 단계로 연결해 구분할 수 있다.
- [ ] NVIDIA 호출이 성공한 뒤 잘못된 타입으로 검증이 실패하는 경우, 로그와 지표에 두 결과가 각각 정확하게 기록된다.
- [ ] 정상 Verify, Provider 오류 및 재시도 시 기존 호출 횟수·토큰·지연시간 집계를 보존한다.
- [ ] 운영 로그의 실패 결과물은 기존 사용자 요청에 따라 인증 정보를 제거하고 출력 크기를 제한한다.
- [ ] 위 성공과 실패 흐름을 실제 분석 경로의 자동 테스트로 검증한다.
