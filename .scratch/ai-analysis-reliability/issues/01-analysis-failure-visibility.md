# 01: 분석 실패 원인과 진행 상태 표시

**What to build:** 채널 분석을 요청한 사용자가 Bot 응답과 분석 상태 화면에서 정상적인 후보 0건과 분석 실패를 구분하고, 실패 단계·유형·복구 가능 여부를 확인할 수 있게 한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 정상 완료 0건, 시간 초과, 구조 검증 실패, 의미 검증 실패를 서로 구분한다.
- [ ] 분석 요청과 세션에 대해 실패 단계, 안정적인 오류 분류, 사람이 이해할 수 있는 요약, 가능한 다음 행동을 제공한다.
- [ ] Bot 응답과 분석 상태 화면에서 실패를 정상 완료 0건으로 표시하지 않는다. 기존 보관 데이터에 상세 정보가 없으면 알 수 없음을 명시한다.
- [ ] 원문, 자격증명, Provider 응답 전체, 내부 스택은 사용자 응답에 노출하지 않는다.
- [ ] 실제로 관측한 수정 후 구조 오류와 의미 검증 실패를 대표 사례로 삼아, 저장·상태 조회·사용자 표시까지 검증한다.

## Context

2026-11-08 전체 스캔은 메시지 33개를 수집했으나 분석 실패로 후보가 저장되지 않았다. 일반적인 수동 재분석 안내가 구체적인 실패 원인을 가렸다. 현재 요청 단위 원자적 저장 정책은 유지한다.
