# 05: NVIDIA 시간 초과 측정과 실행 예산 조정

**What to build:** 운영자가 NVIDIA의 단계별 지연과 완료율을 재현 가능한 평가로 확인하고, 측정 근거에 따라 호출 시간 제한과 세션 예산을 설정할 수 있게 한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 합성 또는 비식별 대표 입력으로 추출·검증·수정 단계의 응답 시간, 시간 초과율, 최종 완료율 및 반환 사용량을 측정한다.
- [ ] 기존 20초 제한을 기준선으로 두고 후보 설정과 비교한다. 입력 규모·모델·thinking 설정·반복 수를 기록한다.
- [ ] 총 세션 예산과 큐 재시도 정책을 함께 고려한 설정 근거를 문서화한다. 검증되지 않은 값으로 기본 제한이나 재시도 횟수를 늘리지 않는다.
- [ ] 시간 초과와 취소 시 Provider 실행, 스트림 및 스케줄러 슬롯이 정리되는지 검증한다.
- [ ] 라이브 평가는 호출·시간·사용량 예산을 명시하고, 실제 입력을 전송하는 경우 기존 운영 승인 경계를 따른다. 오프라인 결과를 실제 Provider 처리량으로 제시하지 않는다.
- [ ] 기본값 변경이 필요하면 기존 시간 제한 ADR에 대한 변경 결정과 운영 적용·롤백 방법을 함께 기록한다.
