# 02: 그래프 생성 계약과 검증 규칙 일치

**What to build:** Decision 분석의 추출·수정 요청이 서버 검증과 일치하는 그래프 계약을 전달하도록 하여, 허용되지 않는 상태값과 잘못된 연결 및 불완전한 Decision Candidate 발생을 줄인다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 추출과 수정에 전달하는 스키마·지침·예시가 노드 종류별 허용 상태값, 연결 대상 및 필수 정보를 일관되게 설명한다.
- [ ] 근거 존재 여부와 rationaleStatus 사이의 일관성 규칙을 명시한다.
- [ ] DecisionCandidate에 Alternative 전용 상태값을 사용하는 사례, 존재하지 않는 노드를 참조하는 연결, 불완전한 후보와 근거 상태 불일치를 회귀 사례로 고정한다.
- [ ] AGY와 NVIDIA의 전송 방식 차이를 유지하면서 같은 도메인 계약을 전달한다. 서버 검증을 완화하거나 잘못된 값을 조용히 보정하지 않는다.
- [ ] 기존 Provider 주입 경계에서 요청 계약과 결과 검증을 확인한다. 실제 AI 품질은 합성 또는 비식별 입력을 사용한 별도 평가로 측정하며 단위 테스트 통과를 품질 보장으로 해석하지 않는다.
- [ ] 저장된 프롬프트 버전의 재개 정책을 보존하고, 버전 변경이 필요하면 기존 분석에 대한 호환 또는 명시적 거절 정책을 함께 검증한다.
