# 03: 서버 변경에 따른 선택·캐시 갱신

**What to build:** 봇 제거·사용자 탈퇴·계정 전환 시 목록과 현재 선택을 갱신하고, 이전 요청과 카드 캐시가 새 화면에 섞이지 않도록 한다.

**Blocked by:** 01: 봇이 설치된 가입 서버만 표시.

**Status:** ready-for-agent

- [x] 현재 선택이 적격이면 유지하고, 제거되면 남은 적격 서버 또는 서버 없음 화면으로 전환한다.
- [x] 서버 제거·사용자 탈퇴·재설치를 목록 재확인에 반영한다.
- [x] 오래된 선택을 기억한 상태와 계정 전환에서 이전 서버 요청·응답·캐시를 차단한다.
- [x] 늦은 설치 조회 결과가 새 무효화 이벤트를 덮어쓰지 않는다.
- [x] 기존 Decision Record와 서버별 데이터 인가 정책은 변경하지 않는다.
- [x] FE 변경은 작업 브랜치와 PR로 제출하고 검증한 submodule 커밋을 기록한다.
- [x] HTTP·브라우저 회귀와 관련 문서를 완성한다.
