# 02: 설치 확인 장애와 재확인 처리

**What to build:** 설치 상태 조회 장애·Bot 오프라인을 미설치와 구분하고, 로그인을 유지하며 필요한 재확인으로 서버 선택을 복구한다.

**Blocked by:** 01: 봇이 설치된 가입 서버만 표시.

**Status:** ready-for-agent

- [x] 신뢰할 수 있는 이벤트 관측과 필요한 Discord 확인으로 설치 인벤토리를 구성한다.
- [x] 외부 목록의 전체 페이지를 확인하고 일부 실패를 완전한 빈 목록으로 취급하지 않는다.
- [x] 동시 재확인을 공유하며 로그인·목록 조회마다 가입 서버별 설치 요청을 무조건 반복하지 않는다.
- [x] Bot 오프라인만으로 설치 서버를 미설치로 판정하지 않는다.
- [x] 장애 시 유효한 로그인은 유지하고 재확인 UI로 복구한다.
- [x] 설치 후 복귀·수동 재확인·재접속으로 새 서버가 나타나고 idle 타이머 조회는 없다.
- [x] 실제 HTTP와 브라우저 경계에서 장애·복구 회귀를 검증한다.
