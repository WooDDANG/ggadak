# 05: 레거시 Decision 이관과 조회 경로 전환

**What to build:** 기존 Decision Record와 검수 이력을 새 기준 저장 형식으로 옮겨, 재시작 후에도 동일한 결정·근거·상태를 조회할 수 있게 한다.

**Blocked by:** 04 — Decision 기준 저장 형식과 검색용 파생값 계약 확립.

**Status:** needs-triage

- [ ] JSON이 없는 레거시 행과 기존 JSON 행을 모두 처리하는 작은 배치 단위의 이관을 제공한다. ID·버전·상태·연결·사용자 편집·의미 있는 과거 필드를 보존한다.
- [ ] 누락된 과거 메시지·확정 시각·작성자·할 일을 만들어내지 않는다. 해석할 수 없는 행은 식별하고 무손실로 보존한다.
- [ ] 재실행·중단·재시작에도 안전하고, 동시 사용자 변경을 덮어쓰지 않는다.
- [ ] 기존/신규 읽기 결과와 검색용 파생값을 대조하며, 이관되지 않은 행과 불일치를 집계한다.
- [ ] 목록·상세·검수·타임라인·후보 이력의 읽기를 새 기준으로 전환한다. 이전 컬럼은 다음 제거 단계까지 유지한다.
