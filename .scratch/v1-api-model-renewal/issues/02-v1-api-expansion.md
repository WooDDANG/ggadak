# 02: v1 API 호환 기반 확장

**What to build:** 기존 결정 조회를 v1 API와 공통 응답으로 제공하고 프론트에서 생성된 클라이언트로 조회한다.

**Blocked by:** 01: BE 미사용 코드와 중복 구현 정리

**Status:** ready-for-agent

- [ ] 기존 결정 조회에 대응하는 v1 경로를 추가하고 기존 API의 응답 계약을 유지한다.
- [ ] v1 성공·에러·검증 실패·404·요청 제한 응답은 success, code, message, data 형식을 사용한다.
- [ ] TSOA에서 OpenAPI와 프론트 클라이언트를 생성하고 결정 조회 화면에 연결한다.
- [ ] 기존·신규 조회 계약과 생성된 클라이언트의 연동을 검증한다.
