# 05: Discord 채널 모니터링 설정

**What to build:** 서버 채널을 선택해 저장하면 봇이 저장된 대상 채널만 모니터링한다.

**Blocked by:** 04: Discord 로그인과 서버 접근 권한

**Status:** ready-for-agent

- [ ] 채널 목록 조회와 모니터링 설정 저장을 화면·API·DB·봇까지 연결한다.
- [ ] 길드·채널·모니터링 설정의 모델과 마이그레이션 및 ERD를 갱신한다.
- [ ] 봇 미설치·접근 불가·다른 서버 채널 선택을 처리하고 CORS 설정을 실제 허용 출처 정책에 반영한다.
- [ ] 재시작 후 설정 보존과 비대상 채널 제외, 채널 권한 변경을 검증한다.
