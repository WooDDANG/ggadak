# 01: BE 미사용 코드와 중복 구현 정리

**What to build:** 현재 수집·조회·검수 동작을 유지하면서 이전 구현의 미사용 코드와 의존성을 제거한다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 중복 AI 추출 엔진, 예전 DB 매퍼·행 타입, SQLite 타입 선언과 사용하지 않는 Google SDK 의존성의 전체 호출·참조를 확인하고 미사용 항목만 제거한다.
- [x] 저장소 재export를 사용하는 테스트를 직접 import로 전환한 뒤 불필요한 호환 파일을 제거한다.
- [x] 실제로 사용하는 추출 프롬프트·검증 스키마와 내부 API, 분석 이력, 마이그레이션 도구는 보존한다.
- [x] 백엔드 빌드와 기존 수집·검수·영속성 회귀 테스트가 통과한다.


## Verification

- 전체 저장소 참조 검색 후 미사용 매퍼·행 타입·SQLite 선언·Google SDK·저장소 호환 export를 제거했다.
- 중복 추출 엔진을 참조하던 기존 E2E는 고정 IAiAdapter 응답 주입으로 전환했다. 필수 requestId와 ADR-0020의 후보별 폐기 의미를 기존 검증에 반영했다.
- Shared 및 BE 빌드, 기존 BE 회귀 테스트와 HTTP 수집·검수/E2E 검증이 통과했다. HTTP 테스트는 임시 로컬 포트에서 실행했고 DB는 테스트 사본만 사용했다.
- 활성 프롬프트·스키마·어댑터·내부 API·분석 이력·마이그레이션은 보존했다.
