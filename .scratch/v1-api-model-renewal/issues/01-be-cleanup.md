# 01: BE 미사용 코드와 중복 구현 정리

**What to build:** 현재 수집·조회·검수 동작을 유지하면서 이전 구현의 미사용 코드와 의존성을 제거한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 중복 AI 추출 엔진, 예전 DB 매퍼·행 타입, SQLite 타입 선언과 사용하지 않는 Google SDK 의존성의 전체 호출·참조를 확인하고 미사용 항목만 제거한다.
- [ ] 저장소 재export를 사용하는 테스트를 직접 import로 전환한 뒤 불필요한 호환 파일을 제거한다.
- [ ] 실제로 사용하는 추출 프롬프트·검증 스키마와 내부 API, 분석 이력, 마이그레이션 도구는 보존한다.
- [ ] 백엔드 빌드와 기존 수집·검수·영속성 회귀 테스트가 통과한다.
