# 10: 대시보드 요약

**What to build:** 선택한 서버의 검수 현황과 최근 결정 카드, 실제 동기화 상태를 대시보드에서 확인한다.

**Blocked by:** 07: Review Queue 검수 흐름 전환, 09: 수동 Discord 동기화

**Status:** resolved

- [x] 확정·보류·검수 대기 건수와 최근 결정, 마지막 성공 동기화 시각·진행 상태를 API와 화면에 연결한다.
- [x] 지표의 집계 범위와 최근 결정 정렬·개수, 동기화 시각의 기준을 명시하고 서버 범위 DB 집계를 사용한다.
- [x] 데이터가 없는 서버와 동기화 진행·실패 상태를 표시한다.
- [x] 검수 및 동기화 이후 지표 갱신과 다른 서버 데이터 미노출을 검증한다.


## Answer

[대시보드 계약·집계 정책](../../../docs/model/dashboard-summary.md). 서버 범위 DB 트랜잭션 집계, 최근 확정 결정 5개, 실제 Sync Job 성공 시각 및 대기/진행/실패 상태, 생성 클라이언트 대시보드와 검수·동기화 후 캐시 갱신을 구현했다. 모델 추가 없이 기존 Decision/SyncJob ERD를 사용한다. BE 대시보드·동기화 4개 테스트, FE 9개 테스트 및 BE/FE 빌드 통과. 빈 서버·최근 정렬·인증·다른 서버 미노출을 확인했으며 운영 DB는 변경하지 않았다.
