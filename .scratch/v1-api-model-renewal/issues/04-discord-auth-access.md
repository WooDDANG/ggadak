# 04: Discord 로그인과 서버 접근 권한

**What to build:** Discord 로그인 후 접근 가능한 서버를 선택하고 해당 서버의 결정만 조회한다.

**Blocked by:** 02: v1 API 호환 기반 확장

**Status:** ready-for-agent

- [ ] OAuth 코드 로그인, JWT 발급·검증과 프론트 로그인·서버 선택 흐름을 연결한다.
- [ ] 사용자·길드·멤버십 관계를 저장하고 Prisma 모델, 데이터 마이그레이션 및 ERD를 반영한다.
- [ ] 선택 서버 전달 방식을 API 계약에 명시하고 다른 서버의 결정 조회와 직접 ID 접근을 차단한다.
- [ ] 기존 데이터의 서버 연결을 보존하고 유효·만료 토큰, 비회원 접근 및 서버 전환을 검증한다.
