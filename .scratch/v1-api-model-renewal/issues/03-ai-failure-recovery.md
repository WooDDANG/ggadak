# 03: AI 공급자 설정과 실패·재시도 처리 정상화

**What to build:** 선택한 AI 공급자로 분석하며 운영 환경의 분석 실패를 정상 결과로 오인하지 않고 같은 Analysis Request로 재시도한다.

**Blocked by:** 01: BE 미사용 코드와 중복 구현 정리

**Status:** ready-for-agent

- [ ] AI_PROVIDER와 키 설정을 하나의 설정 정책으로 적용하고 미지원 공급자·키 누락을 명확히 처리한다.
- [ ] 운영 환경에서는 API 오류·잘못된 응답을 휴리스틱 결정으로 대체하거나 정상적인 무결정 결과로 처리하지 않는다.
- [ ] 휴리스틱 추출은 명시적으로 선택한 개발·테스트 모드에서만 사용하고 테스트는 고정 AI 응답을 주입한다.
- [ ] 실패한 요청은 재시도 가능하게 남고 봇의 실패 표시·처리 반응 정리와 재시도 후 후보 조회를 검증한다.
