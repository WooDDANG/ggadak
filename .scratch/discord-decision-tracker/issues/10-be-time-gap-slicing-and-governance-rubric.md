# 10 — 대화 세션 슬라이싱(30분 공백) 및 4단계 거버넌스 루브릭 채점 엔진

**What to build:**
백엔드 의사결정 추출 코어(`DecisionExtractorCore`)를 구축하여 긴 대화 스트림에서 30분 이상의 발화 공백이 감지될 경우 대화를 독립된 논의 세션들로 분할합니다. 각 세션별로 참여자 수(2인 이상 여부), 동의 이모지 반응 수, 명확한 근거(Rationale) 및 액션 아이템 유무를 분석하여 4단계 거버넌스 점수(4.0 강한 합의 ~ 1.0 불완전/주의)를 계산하고, Express/DB 없이 수 밀리초 만에 검증 가능한 테스트를 구축합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 메시지 타임스탬프를 기반으로 30분 이상 공백 시 대화를 별도 논의 세션으로 분할하는 세션 슬라이서 구현
- [ ] 4단계 거버넌스 루브릭(4.0 / 3.0 / 2.0 / 1.0) 정량 채점 엔진 구현
- [ ] 추출된 결정 후보(`Decision Candidate`) 엔티티에 `governanceScore`와 `consensusStrength` 필드 매핑
- [ ] 순수 대화 메시지 픽스처 배열을 기반으로 세션 분할 및 루브릭 채점을 밀리초 단위로 검증하는 단위 테스트 작성
