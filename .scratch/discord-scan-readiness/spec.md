# Discord 전체 조회 운영 검증

사용자가 선택한 Discord 채널의 수집부터 실제 AI 분석·DB 저장·Web Review Queue 조회까지 연결하고, 서버 전체 조회의 상태·복구 경계를 검증한다. 기존 구현을 활용하고 발견한 오류만 수정한다. 자동 확정이나 인증 우회는 추가하지 않는다.

## 운영 경계

- 루트 환경 설정의 기존 활성 DB를 사용한다. 마이그레이션 전에 현재·legacy SQLite를 검사·백업하고 기존 Decision 보존을 확인한다.
- 필수 서비스 토큰은 루트 설정에서 BE·Bot이 공유한다. 자격증명과 실제 대화 내용은 로그·커밋에 남기지 않는다.
- 대상 서버·채널은 사용자가 알려주거나 FE에서 저장한 모니터링 설정을 따른다. 임의 채널 선택이나 Discord 메시지 전송은 하지 않는다.
- 실제 채널 수집·AI 분석 검증과 테스트 fixture 검증을 구분한다. 사람의 최종 확정은 사용자에게 남긴다.
- 종료된 단계만 완료로 기록한다. 사용자 선택을 기다리는 운영 검증을 구현 완료로 표현하지 않는다.
