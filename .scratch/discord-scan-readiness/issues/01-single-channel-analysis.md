**What to build:** 사용자가 선택한 채널을 스캔하면 실제 AI 분석 결과가 기존 DB에 저장되고 Web Review Queue에서 검수 후보로 조회된다.

**Blocked by:** None (can start immediately).

**Status:** needs-info

- [x] 기존 활성 DB와 legacy SQLite를 검사·백업하고 분석용 마이그레이션을 적용한다.
- [x] 기존 Decision 데이터의 보존과 마이그레이션 적용 결과를 확인한다.
- [x] 사용자가 지정한 채널의 모니터링 설정·Bot 접근 권한을 확인한다.
- [ ] 실제 수집·AI 분석·저장·FE 후보 조회까지 검증한다.
- [x] 발견된 오류를 수정하고 관련 테스트·타입 검사를 통과한다.
