# 웹 로그인과 세션 유지 — 2026-10-16

Status: needs-triage

## 사용자 요구

로그인 실패 원인을 확인하고, 로그인 이후 세션을 유지한다. 사용자가 grill-with-docs를 명시했으므로 설계 결정을 먼저 확인하고 합의한 내용을 기록한다.

## 확인된 사실

- localhost:3000 HTML 제목은 Excalidraw POC - Backend API Integration이다. 현재 이 포트는 GGADDAK FE가 아니다.
- 루트 DISCORD_REDIRECT_URI는 http://localhost:3000/이다. 이 주소로 돌아오면 Excalidraw가 열리는 것이 확인된 경로다. 3002·5173은 조사 시점에 접속되지 않았다.
- GGADDAK FE 원본 HTML 제목은 GGADDAK Decision Dashboard다. Vite 기본 포트는 3000이며 strictPort를 지정하지 않았다.
- access token은 FE 모듈 변수에만 있다. FE 시작 시 서버 세션 복원 경로가 없어 새로고침·브라우저 재시작 시 로그인 화면으로 돌아간다.
- BE access token 15분, DB AuthSession은 최초 로그인부터 고정 7일이다. refresh는 유효한 access JWT를 요구하므로 15분 이상 비활성화된 탭은 현재 방식으로 복원하지 못한다.
- 기존 HttpOnly 쿠키는 OAuth state 검증용 5분 쿠키다. 지속 로그인용 app session cookie가 아니다.
- 로그아웃은 현재 세션을 삭제한다. Discord refresh token은 BE에 암호화해 저장하며 FE로 보내지 않는다.
- 로그의 401은 원인을 확정할 정보가 없고 테스트 트래픽도 섞여 있다. 새로고침 세션 소실과 Excalidraw 콜백은 확인됐지만 모든 로그인 실패를 같은 원인으로 단정하지 않는다.

## 설계 트리

- 서비스 주소 (합의)
  - 제안: Excalidraw 3000을 유지하고 GGADDAK FE는 3002에 고정, 콜백·웹 링크도 일치시킨다.
  - 포트 충돌 때 다른 포트로 자동 이동하지 않고 명확한 시작 오류를 낸다.
  - Discord Portal에도 새 redirect URI 등록이 필요하다.
- 로그인 유지 범위·기간 (합의)
  - 제안: 같은 브라우저의 새로고침·탭 재생성·브라우저 재시작에서 복원한다.
  - 기존 최초 로그인부터 고정 7일 만료를 유지한다. 사용 중 자동 무기한 연장하지 않는다.
- 실패 처리 (합의)
  - 제안: 일시적인 네트워크·BE 장애는 복구 안내로 처리하고, 실제 만료·세션 폐기와 구별한다.
- 위 결정 이후 확인할 항목
  - 현재 브라우저 로그아웃·다중 탭 동기화, 복원 시 guild 권한 갱신과 선택 서버 유지.
  - 쿠키·bootstrap·만료 JWT 복구 경계, CSRF/Origin 검사, 동시 refresh 직렬화.

## Decisions so far

2026-10-16 사용자 “그릴링 전부 예”로 첫 라운드 권장안 3개를 승인했다. GGADDAK FE 3002·일치하는 callback, 같은 브라우저 재시작 복원·최초 로그인부터 7일 고정 만료, 일시 장애와 실제 세션 만료의 구분에 합의했다. 구현·포트 설정·외부 앱 종료는 아직 수행하지 않았다. 기존 로그인 실패 확인 요청은 유지한다.

Q3. 마지막 선택 서버를 기억하되 현재 접근 권한이 있을 때만 복원하고, 권한이 없으면 접근 가능한 서버로 전환할까? 권장: 예.
