# NVIDIA 다중 계정 키 활용

루트 환경 설정의 NVIDIA_API_KEY_1부터 NVIDIA_API_KEY_4까지 서로 다른 네 키를 AI Call에 모두 사용한다. 기존 NVIDIA_API_KEY 단일 키도 호환한다. 번호 키를 우선하고, 빈 값은 제외하며 동일한 키를 중복 예산으로 세지 않는다. 키가 없으면 명확한 설정 오류를 낸다.

Extract·Verify·Repair의 NVIDIA 네트워크 요청에 사용 가능한 키를 공정하게 배정한다. 여러 BE 프로세스가 같은 저장소에서 계정별 호출 예산과 cooldown, 인증 실패 상태를 공유한다. 기존 명세의 계정당 분당 40회를 기본 운영값으로 사용하되 설정 가능하게 한다. SDK의 숨은 재시도는 금지한다. 요청당 하나의 네트워크 생성 시도만 허용하고 429의 Retry-After는 해당 키에 적용한다. 401/403 키는 제외하고 다른 키는 계속 사용할 수 있다. 전체 키가 대기 중이면 Analysis Queue에서 재예약하며, 네트워크 요청 전 대기는 논리 호출 예산·시간 예산을 소비하지 않는다. 모든 키가 인증 실패라면 명확히 실패한다.

AGY 동작은 보존한다. 비밀값은 로그·저장소·오류 응답에 남기지 않고 키 식별자, 선택·성공·실패·대기 상태만 운영자가 확인할 수 있게 한다. 운영 데이터베이스 변경과 배포는 수행하지 않는다. 실제 NVIDIA 인증 검증은 별도 표시하며 자동 테스트에서 외부 호출하지 않는다.

기존 Provider generate 경계와 공유 AI Call/Analysis Queue 경계에서 동작을 검증한다. 다중 프로세스 예약, 네 키 선택, 취소, 재시작, 제한 창 경계, 429·인증 오류, 숨은 재시도 부재를 포함한다. 환경 예시와 운영 문서를 한국어로 갱신한다.
