# 03: 이벤트 관측 불가 시 안전한 접근 복구

**What to build:** 이벤트를 신뢰할 수 없으면 실제 요청에서 새 가입·권한 확인에 성공한 경우에만 접근을 허용하고, 요청 제한 중 추가 호출을 차단한다.

**Blocked by:** 01: 이벤트 관측 기반 권한·서버 목록 정상화; 02: 요청 제한 대기 공유·보존·화면 안내.

**Status:** done

- [x] Bot 단절·intent 미설정·미설치 서버에서 필요한 새 검증 성공으로 해당 요청을 허용한다. 과거 권한의 고정 시간 무조건 재사용은 하지 않는다.
- [x] 진행 중 동시 확인은 공유하며, 순차 요청과 여러 세션에서도 요청 제한 대기를 준수한다.
- [x] 권한 재검증은 JWT 갱신과 분리하고, 실패 후에도 회전된 자격증명을 보존한다.
- [x] 대기 종료 후 사용자의 재시도·실제 접근으로만 복구하고 거절된 쓰기를 자동 재전송하지 않는다.
- [x] 실제 HTTP 및 화면에서 관측 상실·429·자격증명 회전·동시 요청·늦은 응답·수동 복구를 검증한다.
