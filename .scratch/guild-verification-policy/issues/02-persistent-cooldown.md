# 02: 요청 제한 대기 공유·보존·화면 안내

**What to build:** Discord 요청 제한 대기를 같은 사용자의 탭·세션에 공유하고 재시작 후에도 보존하며, 로그인 정보·초안과 남은 대기 시간을 화면에 표시한다.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 유효한 Discord 대기값을 우선하고, 429에 값이 없거나 비정상일 때만 기본 30초를 적용한다.
- [x] 제한 범위와 종료 시각을 저장해 재시작·재로그인·자격증명 회전으로 대기를 우회하지 못하게 한다. 다른 사용자를 불필요하게 차단하지 않는다.
- [x] Discord가 명시한 전체 제한은 실제 해당 요청 주체·적용 범위에 맞게 처리한다.
- [x] 대기 중 추가 외부 호출 없이 남은 시간을 응답하며, 종료 시각이 지나도 타이머만으로 외부 조회하지 않는다.
- [x] FE는 계정명·로그인 상태·초안을 유지하고 서버 데이터와 제출만 차단한다. 일시 장애를 세션 폐기로 처리하지 않는다.
- [x] 실제 HTTP·브라우저 회귀로 대기값·fallback·다중 사용자/세션·회전·재시작·대기 만료와 수동 복구를 검증한다.
