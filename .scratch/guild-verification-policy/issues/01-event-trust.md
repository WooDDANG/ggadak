# 01: 이벤트 관측 기반 권한·서버 목록 정상화

**What to build:** 정상 멤버 이벤트 관측이 있으면 설치 서버의 기존 가입 증명으로 목록·데이터를 제공하고, 설정 누락·관측 공백을 명확히 표시한다.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] Portal·Bot 멤버 이벤트 설정과 실제 연결/전달 연속성을 구분해 운영 상태를 제공한다.
- [x] 미설치 membership만으로 설치 서버 목록 전체를 다시 조회하지 않는다. 가입·설치 변경과 관측 공백에는 필요한 증명을 재확인한다.
- [x] 이벤트나 설치 상태만으로 새 사용자 가입 권한을 부여하지 않으며, 이벤트 이전의 늦은 확인 결과를 거절한다.
- [x] 설정·관측 이상은 로그인 실패나 봇 미설치와 구분해 표시한다.
- [x] 설치/가입 혼합 목록, 빈 목록, 설정 누락, 재설치·가입·탈퇴·재시작 경합을 실제 HTTP 및 화면 경계에서 검증한다.
