## 변경 내용

권한 확인 실패→서버 목록 성공→전체 데이터 재조회→재실패가 반복돼 화면과 요청이 계속 재시작하던 문제를 수정합니다.

```text
첫 권한 오류 → 자동 재확인 1회
  → 실패 지속: 화면·요청 차단, 로그인·초안 유지
  → 수동 재시도: 1회 확인
  → 실제 실패했던 조회 성공: 정상 복구
```

서버 목록 성공이나 관련 없는 조회 성공으로 복구 제한을 초기화하지 않습니다. 지속 실패 중 focus·online이 다시 복구를 시작하지 않으며, 정상 수동 새로고침은 이후 장애의 복구 기회를 소모하지 않습니다. 테스트 Vite 캐시를 격리해 실제 개발 화면과의 충돌도 방지합니다.

## 검증

- 변경 전: 실제 App에서 500ms에21회 자동 재확인을 재현했습니다.
- 변경 후: 실제 화면 회귀 5개와 실제 FE→BE 회귀를 통해 지속 실패·수동 실패/성공·초안 유지·새 장애를 확인했습니다.
- `npm test`, `npm run build` 및 부모 타입 검사·전체 테스트는 pre-commit 검증으로 실행합니다.
- 실제 BE 회귀는 외부 Discord adapter에 429에 해당하는 실패 관측을 주입하며 BE 응답은 대체하지 않습니다.
