## 변경 내용

지속적인 권한 확인 실패가 FE의 자동 서버 재확인·데이터 재조회를 반복시키던 문제를 차단한 FE 커밋 0b1239a를 연결합니다. 실제 FE→BE 장애·수동 복구 회귀를 추가합니다.

```text
지속 권한 오류 → 자동 복구 1회 → 안정적 오류·수동 재시도
장애 해소 + 수동 재시도 → 실제 데이터 조회 복구
```

## 검증

- 변경 전 실제 App에서 500ms에21회 반복을 재현했고 변경 후 회귀가 통과했습니다.
- FE 화면 회귀 5개와 실제 BE의 지속 장애·로그인 유지·수동 복구를 검증했습니다.
- 기존 pre-commit의 타입 검사·전체 빌드·테스트를 Herdr verify pane에서 실행합니다.
- 실제 Discord 외부 관측만 제어하며 BE 응답은 대체하지 않습니다.

## 병합 영향

- 되돌리기 가능. 인증·서버 선택의 복구 흐름과 검증에 영향이 있습니다.
- 기준 fix/frontend-review-followups 이후 사용자가 추가한 기존 hook·DB 설계 문서 커밋 위에서 작업했습니다.
- 새 FE PR의 병합 대기 커밋을 참조하며 기존 PR 브랜치는 변경하지 않습니다.
