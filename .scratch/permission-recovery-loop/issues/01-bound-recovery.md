# 01: 권한 확인 실패의 자동 복구 순환 차단

**What to build:** 권한 확인이 계속 실패해도 화면이 반복 전환되지 않고, 로그인과 편집 초안을 유지하며 수동 재시도로 복구한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 동일 계정·서버의 연속 권한 오류에서 자동 복구는 한 번으로 제한하고 동시 오류는 공유한다.
- [x] 서버 목록 확인 성공 후 데이터 권한 확인이 다시 실패하면 안정적인 오류·수동 재시도 화면에 머문다.
- [x] 지속 실패 중 focus·online·늦은 응답이 자동 복구를 재시작하지 않는다.
- [x] 수동 재시도 실패도 반복하지 않으며, 장애 해소 후 재시도로 데이터와 동일 서버 편집 초안을 복원한다.
- [x] 로그인·쿠키를 유지하고 확인 불가 중 데이터 표시·변경 요청을 차단한다. 계정·서버 변경 시 이전 범위를 정리한다.
- [x] 실제 App 회귀로 지속 실패·동시 오류·수동 실패/성공·정상 갱신·초안 보존을 검증한다.
- [x] 새 FE 브랜치와 별도 한글 PR로 제출한다.
