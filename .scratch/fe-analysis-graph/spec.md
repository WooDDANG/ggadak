# 분석 그래프 디버깅 화면

사용자가 제안한 FE 디버깅 화면을 기존 인증 graph API에 연결한다. AI snapshot은 읽기 전용이다. 새 시각화 패키지 없이 SVG를 사용한다.

- 후보 이력에서 요청 그래프로 진입하고 세션을 선택한다. 확대·축소·화면 맞춤, 로딩·빈 결과·권한·미완료·실패 처리를 제공한다.
- 노드 유형·내용·합의 관찰·관계와 snapshot/current 카드 버전, 억제 상태를 확인하고 현재 카드 상세를 연다.
- 관계 유형 필터, 선택 노드의 인접 관계 강조, discussionProblems 관련 노드·관계 강조를 제공한다.
- guild와 요청별 캐시를 격리하고, 서버 변경·다른 요청 선택 시 이전 결과를 표시하지 않는다. 그래프에 사용자 입력 HTML을 삽입하지 않는다.
- 독립 노드, 순환·자기 참조, 빈 세션, legacy graph 없음에도 화면이 깨지지 않는다.

## 테스트 경계

인증 graph API 호출과 읽기 전용 디버깅 화면을 제안했다. 사용자 응답 대기 중에는 새 테스트를 작성하지 않는다.

## 구현 진행 상태

2026-10-15: 생성 API 클라이언트 갱신, graph 조회 Adapter와 SVG 캔버스 초안을 작성했다. 화면 진입·세션 선택·노드 상세·문제 필터 연결은 아직 미완료다. 사용자 요청에 따라 작업 브랜치에 중간 커밋으로 보존한다.
