# 07: 분석 결과의 독립 처리와 Discord 요약 안내

**What to build:** Bot이 데이터 전송과 별도로 분석 결과를 처리하고, Discord 반응과 검사 안내를 필요한 상태 변화에만 갱신한다.

**Blocked by:** 02, 06

**Status:** ready-for-agent

- [ ] 데이터 전송 완료와 분석 결과 수신을 분리한다. Bot은 결과 처리 때문에 전송을 기다리지 않고 별도 비동기 작업으로 BE의 보관 결과를 반영한다.
- [ ] 결과 알림이 유실되거나 Bot이 재시작해도 결과 재조회로 복구한다. 결과 식별자별 중복 처리를 막고 실제 Discord 변경 성공을 확인한 뒤 반영 상태를 보존한다.
- [ ] 전수검사는 개별 반응 대신 실행자에게 비공개 시작·최종 종료 또는 실패·대기 요약을 제공한다. 데이터 전달 완료를 분석 종료 안내로 혼동하지 않는다.
- [ ] 실시간·수동 분석은 기존 반응 의미를 유지하되 완료한 정리를 매초 반복하지 않는다. 복구 sweep의 중복 실행과 무제한 예약을 막고 실패한 정리는 제한된 간격으로 재시도한다.
- [ ] fake Discord·느린 AI로 전송과 결과 처리의 병행, 완료 중복·연결 끊김·재시작·결과 유실 복구와 실제 호출 수를 검증한다.
