# 08: 변경 중심 체크포인트 복구

**What to build:** 변경된 분석 완료 범위와 시작 시 복구만 처리하고 변경 없는 채널을 매초 조회하지 않는다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 중복 복구를 합치고 변경 없는 주기에 과거 채널 수에 비례하는 체크포인트 GET을 발생시키지 않는다.
- [ ] BE 확인 전 변경을 보존하고 처리 중 새 변경·장애·응답 유실·재시작을 복구한다.
- [ ] ADR-0020의 연속 완료 범위 규칙을 유지한다. 수신만 끝난 범위나 후속 범위의 성공으로 앞선 미완료 범위를 건너뛰지 않는다.
- [ ] 기존 분석 경로에 독립적으로 적용 가능하게 하고 BE 큐 기반 분석도 같은 완료·체크포인트 규칙으로 연결한다. Bot과 BE가 각각 체크포인트를 앞당기는 이중 소유를 만들지 않는다.
- [ ] 격리 테스트로 유휴 요청 수·중간 실패·동시 완료·늦은 응답·재시작을 검증한다.
